# Dibs packs

- `categories.json`: the category pack. Category names only: there are no answer lists, because the group judges every answer.
  - `id`: `DB-` and a number; never reuse one.
  - `name`: the category as players read it.
  - `tag`: `family` (any age, 8 and up) or `adult` (grown-up topics, never explicit). The host's Categories setting picks Family only or Everything.
- Writing rule: a category needs answers for at least 15 of the game's 20 letters (A to Z without Q, U, V, X, Y and Z).
- **The 40 starter categories haven't been checked against the 15-of-20 rule.** Grow the pack to about 100 before Dibs is marked Playable, so a night doesn't repeat a category.
