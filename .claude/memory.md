## Lessons Learned
- Chainword's rules advance to the next word the moment a word is done, so any "how did that word go" view has to be held by the screen (PhoneScreen keeps a review index). That was the missing feedback on the last guess.
- Headless Edge test runs: give each run its own debugging port and kill the whole process tree (`taskkill /T /F`), or the next run attaches to a dead browser. A full Chainword run can take over 90 seconds on this PC; keep safety timers well above that.
- Don't put JS template literals (backticks) inside `node -e "..."` in the Bash tool: bash runs them as commands and silently blanks the text. Write the edit script to a file in the scratchpad instead.
- Most repo files use CRLF line endings; scripted find-and-replace must match `\r\n` (or normalize first).
- Headless Edge screenshots below about 500px wide are clipped by its minimum window size. Set the viewport over the DevTools protocol instead (`Emulation.setDeviceMetricsOverride`).
- Windows file names are case-insensitive: `HostSettings.tsx` and `hostSettings.ts` collide. Hooks live in `useX.ts` files, which avoids it.
- Stopping a background `npx vite preview` task leaves the node child running on its port. Find it with `Get-NetTCPConnection -LocalPort 4173` and stop that PID.
- To see a design prototype (`*.dc.html` + `support.js`), serve its folder (`npx http-server`) and drive it in headless Edge; find phones by their 390x844 size, not by label text.
- Synthetic Enter key presses over the DevTools protocol need `text: "\r"` to activate a button.
- Bebas Neue (game-show label font) has no lowercase. Never set the site address in it: the `/juju-studios` path is case-sensitive on GitHub Pages, so an all-caps address would 404 if typed.
- Long heredocs with template literals can break the Bash tool ("unexpected EOF"); write edit scripts to the scratchpad with the Write tool instead.
- Python isn't installed on this PC; use node for one-off scripts.
- Before starting the Firebase emulators, check ports 9000, 9099 and 4000: Julian may already have them running (2026-11-13). Never kill a process you did not start.
- Headless Edge: a scripted `element.click()` is not a user gesture, so `signInWithPopup` gets blocked. Use `Input.dispatchMouseEvent`. Email-link tests read the link from the Auth emulator at `/emulator/v1/projects/juju-studios/oobCodes` (2026-11-13).
- Some repo files are CRLF and some LF. Text replacements in scripts must normalize line endings first or they silently miss. PowerShell 5 `Set-Content -Encoding utf8` adds a BOM: use node or the Edit tool instead (2026-11-13).
- Testing database rules over the emulator's REST API: send a player's ID token as `?auth=<token>`. An `Authorization: Bearer` header is treated as an admin access token and skips the rules, which made every check pass falsely and wrote bad flags (2026-11-13). Real verified tokens come from the Auth emulator's `accounts:sendOobCode` plus `accounts:signInWithEmailLink`.
- Pin Drop map pins are built as HTML strings for Leaflet: anything from another player must be escaped (`escapeHtml` in PinMap.tsx) and validated by the rules. Room entries had no checks until 2026-11-13.
- Never clean up headless test browsers with `taskkill /IM msedge.exe`: it closes Julian's own Edge windows too. Kill only the spawned process tree by PID (`taskkill /PID <pid> /T /F`).
- Headless Edge touch drags (`Input.dispatchTouchEvent`) sometimes stall a run; a retry passes. Give scripts their own timeout so a stall can't hang the shell.
- Pin Drop's room runner used to reload `latest` from every room update, so an input could be applied to a state the room hadn't caught up on (lost lock-ins). Runners must read the game once at start and own it after (Dial It In pattern) (2026-11-13).
- Leaflet runs a 250 ms timer after any zoom animation that doesn't check whether the map was removed; removing a map mid-zoom throws `_leaflet_pos`. Maps that are about to be replaced should not animate (`animate: false`) (2026-11-13).
- A headless Edge driver over CDP needs no packages: Node 26 has a global WebSocket. Separate phones are `Target.createBrowserContext`s on one browser. Email-link sign-in: build the app URL from the emulator oobLink's continueUrl plus apiKey, oobCode and mode=signIn.
